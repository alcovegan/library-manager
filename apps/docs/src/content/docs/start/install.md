---
title: Установка
description: Как установить Library Manager на macOS и Windows и что происходит при первом запуске.
---

Desktop-приложение собирается для **macOS (Apple Silicon)** и **Windows**. Сборки публикуются в
[GitHub Releases](https://github.com/alcovegan/library-manager/releases).

## macOS

1. Скачайте `Library-Manager-<версия>-arm64.dmg` из последнего релиза.
2. Откройте образ и перетащите **Library Manager** в «Программы».
3. При первом запуске macOS может предупредить, что разработчик не подтверждён: приложение не
   нотаризовано. Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите
   **«Всё равно открыть»**.

:::note
Сборки только для Apple Silicon (arm64). Отдельной сборки для Intel-маков нет.
:::

## Windows

Скачайте один из вариантов:

- `Library-Manager-Setup-<версия>.exe` — обычный установщик;
- `Library-Manager-<версия>.exe` — portable-версия без установки.

SmartScreen может показать предупреждение о неизвестном издателе: сборки не подписаны. Нажмите
**«Подробнее» → «Выполнить в любом случае»**.

## Первый запуск

При первом запуске приложение создаёт пустую библиотеку. Дальше есть три пути:

- добавлять книги вручную — см. [Книги и обложки](/guide/books/);
- импортировать CSV/TSV-таблицу — см. [Импорт и экспорт](/guide/import-export/);
- подключить синхронизацию и скачать библиотеку с другого устройства — см. [Синхронизация](/guide/sync/).

Где хранятся данные и как сделать резервную копию — в разделе [Данные и приватность](/reference/data/).

## Обновления

Обновления проверяются по кнопке **«Проверить обновления»** в шапке: автоматической проверки при
запуске нет. Если на GitHub есть новая версия, приложение сообщит об этом и скачает её в фоне, а
после загрузки предложит установить и перезапуститься.

Обновления работают только в установленной версии, при запуске из исходников (`npm run dev`) — нет.
