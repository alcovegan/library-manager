## Бэкап (JSON)

Кнопка **«Бэкап»** (стрелка вниз) в шапке сохраняет всю библиотеку в один файл
`library-backup-ГГГГ-ММ-ДД.json`. В него входят:

- книги **вместе с обложками** (встроены в файл);
- места хранения, коллекции, сохранённые поиски;
- пользовательские значения справочников;
- история чтения.

Файл самодостаточный: его можно хранить где угодно и восстановить на другом компьютере.

## Восстановление из бэкапа

Кнопка **«Импорт резервной копии»** (стрелка вверх). Импорт **сливает** данные с текущей
библиотекой, ничего не удаляя:

- книга считается дублем, если совпадает ISBN (ISBN-10 и ISBN-13 приводятся к одному виду), а без
  ISBN — название и авторы;
- дубли пропускаются, остальные добавляются;
- в конце показывается отчёт: сколько добавлено и сколько пропущено.

## Импорт CSV/TSV

Кнопка **«Импорт CSV/TSV»** (ящик со стрелкой) открывает мастер импорта:

1. Выберите файл. Разделитель (`;`, `,`, табуляция или `|`) определяется автоматически. Если в
   первой строке нет заголовков, поставьте флаг **«Нет заголовков»**.
2. Сопоставьте колонки файла с полями: название, авторы, ISBN, издательство, год, язык, серия, номер
   в серии, формат, жанры, теги, рейтинг, заметки, ссылка на обложку.
3. Проверьте предпросмотр и запустите импорт.

Если указана колонка со ссылкой на обложку, обложки скачиваются автоматически.

:::note
CSV-импорт не переносит места хранения, статусы чтения и данные Goodreads — только поля из списка
выше. Для полного переноса используйте [бэкап JSON](#бэкап-json).
:::

Если в таблице нет ISBN, их можно сначала подобрать через
[пакетное обогащение](/guide/metadata/#пакетное-обогащение-csv).

## Экспорт журнала

[Журнал изменений](/guide/vocabulary/#журнал-изменений) экспортируется отдельно, в JSON.

:::caution
Экспорта библиотеки в CSV, Excel или PDF пока нет — только бэкап JSON.
:::
