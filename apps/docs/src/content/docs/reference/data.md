## Где лежат данные

Вся библиотека хранится локально, в папке данных приложения:

| ОС | Путь |
|---|---|
| macOS | `~/Library/Application Support/Library Manager/` |
| Windows | `%APPDATA%\Library Manager\` |
| Linux | `~/.config/Library Manager/` |

Внутри, в подпапке `data/`:

| Файл | Что это |
|---|---|
| `library.db` | База SQLite: книги, авторы, коллекции, места, история |
| `covers/` | Обложки |
| `settings.json` | Настройки, ключи API и токены облаков |
| `device-id.txt` | Идентификатор устройства для синхронизации |

## Что уходит наружу

| Куда | Что | Когда |
|---|---|---|
| Open Library / ISBNdb | ISBN | Поиск по ISBN |
| OpenAI / Perplexity | Название, авторы, издательство, год | AI-поиск ISBN и Goodreads |
| Goodreads | Запрос страницы книги | «Найти на Goodreads» |
| Google Books, DuckDuckGo | Название и автор | Поиск обложки онлайн |
| Ваше облако | База, обложки, настройки **без ключей и токенов** | Синхронизация |
| GitHub | Запрос версии | «Проверить обновления» |

Больше никуда данные не отправляются, аналитики и телеметрии нет.

:::caution
`settings.json` хранит ключи API и токены облаков **открытым текстом**. Не выкладывайте папку данных
целиком в общий доступ.
:::

## Резервные копии

- **Бэкап JSON** из интерфейса — см. [Импорт и экспорт](/guide/import-export/#бэкап-json).
  Содержит книги с обложками, но не ключи.
- **Копия папки данных** — полная копия, включая настройки. Закройте приложение перед копированием.
- **Синхронизация** тоже служит копией: данные лежат в вашем облаке.
