## Desktop

| Что | Как на самом деле |
|---|---|
| Нечёткий поиск | Библиотека Fuse.js не загружается в изолированном preload-скрипте Electron, поэтому поиск ищет только точные вхождения, без учёта опечаток |
| Разбор CSV | По той же причине вместо PapaParse работает упрощённый парсер. Сложные CSV (переносы строк внутри кавычек) могут разобраться неверно |
| S3-синхронизация | Включить S3 из интерфейса нельзя: выбор сохраняется только для облачных провайдеров |
| Автосинхронизация и очистка обложек | Видны для любого провайдера, работают только с S3. Автосинхронизация только скачивает данные |
| Коллекции по фильтру | Создать из интерфейса нельзя — только статические. Вместо них — сохранённые поиски |
| Google Books API Key | Сохраняется в настройках, но не используется. Поиск обложек берёт ключ только из переменной окружения |
| Английский интерфейс | Перевод неполный: сообщения, диалог синхронизации и подписи карточек остаются на русском |
| Экспорт | Только бэкап JSON и журнал. Экспорта в CSV, Excel или PDF нет |
| Выдача книг | Нет сроков возврата и напоминаний |
| Подпись приложения | Сборки не подписаны и не нотаризованы — при первом запуске macOS и Windows предупреждают |

## Мобильное приложение

| Что | Как на самом деле |
|---|---|
| Добавление книг и обложек | Нет: книги заводятся на desktop |
| Статус чтения, места хранения | Не показываются и не редактируются |
| S3 | Только скачивание базы с desktop |
| Определение офлайна | По запросу к внешнему сервису `httpbin.org`. Если он недоступен, приложение решит, что сети нет |
| Android | Код совместим, но сборки не публикуются. Bundle ID Android отличается от iOS |
