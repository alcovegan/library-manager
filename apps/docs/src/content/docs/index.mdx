import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

## Что умеет

<CardGrid stagger>
	<Card title="Каталог книг" icon="open-book">
		Название, авторы, серия, издательство, ISBN, формат, жанры, теги, рейтинг и заметки. Обложки
		подгружаются из файла, по ссылке или поиском в интернете.
	</Card>
	<Card title="Автозаполнение по ISBN и AI" icon="rocket">
		Метаданные по ISBN из Open Library или ISBNdb. AI (OpenAI или Perplexity) подсказывает ISBN
		по названию и находит рейтинг на Goodreads.
	</Card>
	<Card title="Мощный поиск" icon="magnifier">
		Операторы AND / OR / NOT, поля `author:`, `series:`, `year:>=2000`, фильтры по формату и
		статусу, сохранённые поиски.
	</Card>
	<Card title="Полки и выдача" icon="list-format">
		Места хранения с кодами полок, история перемещений, учёт того, кому отдана книга.
	</Card>
	<Card title="Чтение и статистика" icon="approve-check">
		Статусы «Хочу прочитать», «Читаю», «Прочитано» и другие, даты и история прочтений, статистика
		по годам.
	</Card>
	<Card title="Синхронизация" icon="laptop">
		Яндекс Диск, Google Drive, Dropbox или S3. Слияние изменений между компьютером и телефоном.
	</Card>
</CardGrid>
